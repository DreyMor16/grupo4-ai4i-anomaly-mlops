## Exploración de gamma en One-Class SVM

Antes de definir el rango de gamma para el Experimento 4, se realizó una prueba exploratoria utilizando One-Class SVM con gamma = scale, el enfoque semi-supervised y el feature set engineered_only. El valor efectivo calculado por scikit-learn fue 0.4851 para un conjunto de 6 variables. Este valor se utilizará como referencia para definir un rango de búsqueda más específico alrededor de gamma en el siguiente experimento.
